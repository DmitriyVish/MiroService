**Describe logic of file evaluate_responses.py:**

Как это работает:

1. Загрузка данных

Читает results_question_1.xlsx, берёт колонки «Роль агента» и «Ответ».

2. Поиск эталона

Находит ответ от generative_ai_qwen — он будет базой для сравнения.

3. Векторизация текста

Использует модель all-MiniLM-L6-v2 (лёгкая, быстрая, подходит для русского языка).

Превращает тексты в векторы (числовые представления смысла).

4. Сравнение по косинусному сходству

Вычисляет угол между векторами эталона и ответа кандидата.

Результат переводится в оценку от 0 до 10 (10 = полное совпадение).

5. Генерация комментария

На основе оценки выдаёт краткий вывод (см. функцию generate_comment).

6. Сохранение в Excel

Создаёт файл evaluation_results.xlsx с колонками:

Номер вопроса  Роль  Ответ Комментарий  Оценка

 Зависимости:
 ```
 pip install pandas scikit-learn sentence-transformers openpyxl

 ```


**Describe logic of file evaluate_responses_multi_question.py**:
Что изменилось

1. Список входных файлов

INPUT_FILES содержит пути к 4‑м Excel‑файлам.

Можно легко добавить/убрать вопросы.

2. Цикл по вопросам

Для каждого файла:

Загружает данные.

Находит эталон (generative_ai_qwen).

Сравнивает ответы остальных ролей.

Добавляет номер вопроса (file_idx).

3. Обработка ошибок

Проверяет наличие файла.

Ловит ошибки при чтении Excel.

Пропускает вопросы без эталона.

4. Единый выходной файл

Все результаты складываются в один evaluation_results.xlsx.

Колонка «Номер вопроса» позволяет различать ответы по задачам.

**Примечания**

Модель all-MiniLM-L6-v2 загрузится один раз при старте (не для каждого вопроса).

Если какой‑то файл отсутствует — скрипт сообщит об этом и продолжит работу.

Для большего числа вопросов просто добавьте пути в INPUT_FILES.

Для русского языка модель даёт достаточную точность; для критически важных задач можно заменить на paraphrase-multilingual-MiniLM-L12-v2.
